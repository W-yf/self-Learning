## 换电脑后开始

先同步本仓库，再读根 STATUS 和本 README，接续 Mario 首次尝试。用同一个个人 GitHub 账号打开 [cs50.dev](https://cs50.dev/)，按照 [官方环境说明](https://cs50.readthedocs.io/cs50.dev/) 创建或打开课程 codespace；当前尚未验证登录、环境和工具可用性。使用课程云端环境时，家中电脑不需要另装本地 C 工具链。

本仓库不包含课程作业代码，拉取本仓库后仍须打开课程环境才能编写和验证。结束时确认作业文件已保存在课程环境，再将不含解答的笔记、必要验证摘要与下一步同步到本仓库。
